Mem0 ingestion used 490 model calls, 7,712,359 input tokens and 394,401 output tokens. The preliminary input projection was 7.4 million. Summed session client time was 29,385 seconds (about 8 hours 10 minutes), excluding gaps. The bridge recorded 512 attempts including all answer, judge and superseded-pilot calls, below the 1,500 cap. Actual monetary cost was not measured.

The Mem0 and dense readers received the same estimated 6,000-token content budget. Across the ten cases, Mem0 reader input was 109,443 tokens and dense reader input was 108,007. Mem0 ingestion is a separate upfront cost; the methods selected different content and their retrieval timing paths differed.

Evidence presence means all labelled evidence session identifiers appeared in selected memory metadata. It does not verify the original evidence turns. GPT served as both answer model and judge, and the histories are public benchmark data. The first pilot was selected before the remaining cases; the small sample and model grading limit the conclusions. The local resource sample covers only part of the initial ingestion and does not measure remote inference.
