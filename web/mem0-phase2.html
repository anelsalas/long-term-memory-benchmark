These selected cases are a small pilot, graded by GPT. More questions and independent review will test how broadly the result holds.

Usage and preparation

Mem0 processed 490 conversation sessions in 490 extraction calls, using 7,712,359 input and 394,401 output tokens. Its reader used 109,443 input tokens across ten answers; dense search used 108,007.

Session processing totaled about 8 hours 10 minutes, excluding gaps. This is preparation time on the tested setup; actual monetary cost was not measured.

Evidence and interpretation

Selected memories referenced all labelled evidence sessions in each case. This measures session-level provenance. The two retrieval methods chose different content; their timing paths differed.
