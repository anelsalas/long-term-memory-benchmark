What this checks

The same Qwen3-0.6B model answers the same 20 questions using four evidence conditions. Known evidence supplies the actual correction record. Seeds 42–61 vary scores in one fixed story template; condition order rotates evenly.

Accuracy is strict agreement with the ledger's integer answer. For question-only requests, gold agreement is a guessing diagnostic; an UNKNOWN response is the requested abstention. Each request starts a new conversation.

Interpretation and scope

Inspect the recorded answers below to separate evidence selection from answer formatting and output limits. The prompt requests an integer or UNKNOWN. This prompt differs from the earlier two-request smoke, which requested only an integer.

Timing includes local model response and transport; the first request includes loading. Order is balanced; timings are descriptive. Input token usage is unavailable from this service. CPU and RAM samples in the downloadable repository report cover the runner process. Model-worker resources and energy remain separate measurements.

These compact development cases test correction handling. Broader task coverage and held-out evaluation follow before ranking memory systems.
